# 1. Description

I created an animation of Collecting Duct cells in physical xy space, linearly reduced dimension PCA space, and nonlinear dimensionality reduciton tSNE space. Although I could not include it in the figure, I had used a dotplot and found the significantly overexpressed genes in my cluster 2 such as "Nccrp1"  "Slc12a1"  "Scin"   "Ppp1r1a" "Scel" that are very important to the function of intercaated cells in the collecting duct. For example, Scin is very important to intercalated cells for acid secretion in the collecting duct (https://pubmed.ncbi.nlm.nih.gov/29089413/). Scel is also present in some colelcting duct cell populations that express mesenchymal properties (https://pmc.ncbi.nlm.nih.gov/articles/PMC4279727/). Meanwhile, Pbb1r1a and Slc12a1 are also present in the collecting duct (https://insight.jci.org/articles/view/94716).

Through this animation, we can see that the collecting duct cells cluster together across all three spaces. In physical space, they are tightly distributed in the center of the medulla, consistent with the known anatomical location of the collecting duct. In PCA and t-SNE space, they similarly form a salient unambiguous group. Particularly, these cells appear transcriptomically distinct from other cell types in PCA space, they are well separated along PC1 and PC2, which capture the greatest axes of variation. Because PCA is a linear dimensionality reduction, this separation suggests that collecting duct cells have a markedly different expression profile from the other populations. This distinctness is further supported in the t-SNE plot, where the collecting duct cluster shows minimal overlap with any other cluster.

data <- read.csv('/Users/willli/Documents/BME 25-26/Genomic Data Visualization/genomic-data-visualization-2026/data/Visium-IRI-ShamR_matrix.csv.gz')

## PCAs

toppcs <- pcs$x[, 1:20]
tsne <- Rtsne::Rtsne(toppcs, dims = 2, perpexity = 30)
emb <- tsne$Y
rownames(emb) <- rownames(mat)
colnames(emb) <- c('tsne1', 'tsne2')


clusters <- as.factor(kmeans(toppcs, centers=5)$cluster)
names(clusters) <- rownames(mat)
df <- data.frame(emb, clusters, pos, pcs$x, gene=mat[ , 'Aqp3'])

ggplot(df, aes(x = tsne1, y = tsne2, col = clusters)) + geom_point()
ggplot(df, aes(x = x, y = y, col = clusters)) + geom_point()

head(vargenes)

ggplot(df, aes(x=tsne1, y=tsne2, col=clusters)) + geom_point()

})
