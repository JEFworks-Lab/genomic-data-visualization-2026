### Make a new data visualization of the multi-cellular spot resolution spatial transcriptomics sequencing dataset. Compare your result with the clustering and differential expression analysis you did previously in HW3/4. Explain how your results are similar or different. Create a data visualization comparing all three analyses. Write a brief description of your figure so we know what you are visualizing.
Panel 1. shows how the reference-free deconvolution of the Visium dataset using STdeconvolve provides additional biological interpretation by estimating cell-type proportions within each Visium spot, which has a multi-cellular resolution. Panel 2. demonstrates how k-means clustering of the Visium and Xenium datasets, on the left and right, respectively, assigns each spot to a single discrete cluster, compared to panel 1. where STdeconvolve models each Visium spot as a mixture of multiple cell types, hence reflecting their multi-cellular nature more accurately. As a result, k-means clustering results in showing sharper boundaries between cell types, whereas deconvolution portrays gradual boundaries between cell type proportions. Furthermore, k-means clustering on the Xenium dataset reveals a higher, single-cell resolution that captures finer-grained patterns compared to the deconvolution or k-means clustering of the Visium dataset.

Panel 3. demonstrates how cell type 8 from reference-free deconvolution of the Visium dataset, cluster 5 from k-means clustering of the Visium dataset, and cluster 1 from the k-means clustering of the Xenium dataset all appear in a moderately similar anatomical area of the tissue, forming a ring-like region in the physical space. Given that a similar ring-like region was also found from the cluster of interest as determined by k-means clustering of the Xenium and Visium datasets in HW3 and HW4, respectively, this repeatedly indicates agreement regarding the presence of a transcriptionally distinct cluster of cells between both reference-free deconvolution and k-means clustering.

Panel 4. indicates that the top 10 genes identified as strong markers of the transcriptionally distinct cluster of cells in panel 3. are consistent across reference-free deconvolution and k-means clustering. Acsm3, the top marker from STdeconvolve of the Visium dataset, is also found as the 10th and 5th markers from k-means clustering of the Visium and Xenium datasets, respectively. Furthermore, Cyp7b1 and Aqp1, which are the 10th and 3rd markers from STdeconvolve of the Visium dataset, are also identified as the 4th and 7th markers from k-means clustering of the Visium and Xenium datasets, respectively. To further support the biological validity of the cluster identified, Bcat1 is the top marker from k-means clustering of both the Visium and Xenium datasets; Bcat1 was the top marker from k-means clustering of the Xenium dataset in HW3; and Slc22a19, Serpina1d, Cyp7b1, Scd1, Serpina1f, and Slc22a13 were all top markers from k-means clustering of the Visium dataset in HW4.

The similarities and differences between my analyses in EC2, HW3, and HW4 highlighted above are derived from this figure in EC2, comparing three analyses of the Visium and Xenium spatial transcriptomics datasets of the same spleen tissue: STdeconvolve reference-free deconvolution, k-means clustering, and differential gene expression analysis. The top row, containing panels 1. and 2., shows spatial maps of Visium spots colored by inferred cell types from STdeconvolve, Visium spots colored by inferred clusters from k-means clustering, and Xenium spots colored by inferred clusters from k-means clustering. The middle row that contains panel 3. highlights the spatial localization of a transcriptionally distinct cluster of cells in the physical tissue space. The bottom row displays the top gene markers associated with these distinct populations identified in panel 3. Overall, this figure compares how each of the methods for cell type/cluster identification distinguish biologically meaningful spatial patterns and corresponding gene markers.

```r
# Load the necessary libraries and set the seed
library(ggplot2)
library(STdeconvolve)
library(ggrepel)
library(patchwork)
set.seed(3236)

# Read in Visium data
data_vis <- read.csv('~/Documents/genomic-data-visualization-2026/data/Visium-IRI-ShamR_matrix.csv.gz')
pos_vis <- data_vis[,c('x', 'y')]
rownames(pos_vis) <- data_vis[,1]
gexp_vis <- data_vis[, 4:ncol(data_vis)]
rownames(gexp_vis) <- data_vis[,1]

# Read in Xenium data
data_xen <- read.csv('~/Documents/genomic-data-visualization-2026/data/Xenium-IRI-ShamR_matrix.csv.gz')
pos_xen <- data_xen[,c('x', 'y')]
rownames(pos_xen) <- data_xen[,1]
gexp_xen <- data_xen[, 4:ncol(data_xen)]
rownames(gexp_xen) <- data_xen[,1]

# Get gene list from Xenium data and subset Visium to Xenium genes
# Reference: Code from Lecture 10
genes_have <- intersect(colnames(gexp_xen), colnames(gexp_vis))
gexp_sub_vis <- gexp_vis[, genes_have, drop = FALSE]

# Deconvolve Visium data
# References: Code from Lecture 10, https://jef.works/STdeconvolve/getting_started.html
lda_vis <- fitLDA(gexp_sub_vis, Ks = seq(2, 10, by = 1))
optLDA_vis <- optimalModel(models = lda_vis, opt = "9")
res_vis <- getBetaTheta(optLDA_vis, perc.filt = 0.05, betaScale = 1000)
deconProp_vis <- res_vis$theta
deconGexp_vis <- res_vis$beta

# Visualize all cell type proportions in theta
# References: Code from Lecture 10, https://jef.works/STdeconvolve/getting_started.html
# Prompt to AI: "What are the exact HEX codes for each of the colors used in the rainbow-style palette of STdeconvolve using Ks = 9?"
p1 <- vizAllTopics(deconProp_vis, pos_vis, r = 40) +
  theme_test() +
  labs(title = "Visium: Deconvolution", x = "x", y = "y", fill = "Cell Type") +
  scale_fill_manual(
    values = c(
      "X1" = "#FF0000", "X2" = "#FF9900", "X3" = "#CCFF00",
      "X4" = "#00FF00", "X5" = "#00FF99", "X6" = "#0099FF",
      "X7" = "#0000FF", "X8" = "#9933FF", "X9" = "#FF33AA"
    ), labels = function(x) gsub("^X", "", x)
  ) +
  coord_fixed() + 
  theme(plot.title = element_text(face = "bold"),
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5)) +
  guides(color = "none")

# Visualize the deconvolved cell type 8
# References: Code from Lecture 10, https://jef.works/STdeconvolve/getting_started.html
p4 <- vizTopic(theta = deconProp_vis, pos = pos_vis, topic = "8",
         size = 1.5, stroke = 0, alpha = 1.0, low = "lightgrey", high = "#9933FF") + 
  theme_test() +
  labs(title = "Visium: Cell Type 8 in Physical Space", x = "x", y = "y", fill = "Proportion") +
  coord_fixed() +
  theme(plot.title = element_text(face = "bold"),
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5)) +
  guides(color = "none", fill = guide_colorbar(frame.colour = NA))
p4

# Subset and visualize the top ten gene markers for cell type 8
# Prompts to AI: "I ran STdeconvolve on Visium spatial transcriptomics data and obtained the beta matrix (deconGexp_vis), where rows are inferred cell types and columns are genes. 
# How can I identify the top marker genes for a specific cell type (i.e., cell type 8) and visualize the top 10 genes using a horizontal bar plot in ggplot2?"
top_genes <- sort(deconGexp_vis[8,], decreasing = TRUE)[1:10]
df <- data.frame(gene = names(top_genes), weight = top_genes)
p7 <- ggplot(df, aes(x = reorder(gene, weight), y = weight, fill = weight)) +
  geom_bar(stat = "identity") +
  coord_flip() + 
  scale_fill_gradient(high="#9933FF", low = "#D1A3FF") +
  theme_test() +
  theme(legend.position = "none") +
  labs(
    title = "Visium: Top Gene Markers for Cell Type 8",
    x = "Gene",
    y = "Transcriptional Profile (Beta)"
  ) +
  theme(plot.title = element_text(face = "bold"))

# Normalize Visium data
totgexp_vis <- rowSums(gexp_vis)
mat_vis <- log10(gexp_vis/totgexp_vis * 1e6 + 1)

# PCA on Visium data
pcs_vis <- prcomp(mat_vis, center=TRUE, scale=FALSE)
plot(pcs_vis$sdev[1:50]) # Scree plot: Will perform tSNE on top 10 PCs as it reaches the elbow of the graph

# Determining the optimal k value for K-means clustering of Visium data
totw_vis <- sapply(2:25, function(k) {kmeans(pcs_vis$x[,1:10], centers = k, nstart = 10, iter.max = 500, algorithm = "Lloyd")$tot.withinss})
df_totw_vis <- data.frame(k = 2:25, tot.withinss = totw_vis)
ggplot(df_totw_vis, aes(x = k, y = tot.withinss)) + geom_point() + geom_line() + theme_test() # Scree plot: Optimal k = 9 found for K-means clustering

# K-means clustering of Visium data
clusters_vis <- as.factor(kmeans(pcs_vis$x[,1:10], centers = 9)$cluster)

# Visualize all clustered cell types for Visium data
df_km_vis <- data.frame(pos_vis, clusters_vis)
p2 <- ggplot(df_km_vis, aes(x = x, y = y, col=clusters_vis)) + 
  theme_test() +
  labs(title = "Visium: K-Means Clustering", color = "Cluster") + 
  geom_point(size = 1.0) +
  scale_color_manual(values = c(
    "1" = "#FF0000", "2" = "#FF9900", "3" = "#CCFF00",
    "4" = "#00FF00", "5" = "#00FF99", "6" = "#0099FF",
    "7" = "#0000FF", "8" = "#9933FF", "9" = "#FF33AA"
  )) + 
  coord_fixed() +
  theme(plot.title = element_text(face = "bold"),
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5))

# Define labels for cluster 5 versus other clusters
cluster_label_vis <- ifelse(clusters_vis == 5, "5", "Other")
# Define colors for cluster 5 versus other clusters
cluster.cols_vis <- c("Other" = "lightgrey", "5" = "#00FF99")
# Define cluster of interest
clusterofinterest_vis <- clusters_vis == "5"
othercells_vis <- clusters_vis != "5"

# Visualize cluster 5 in physical space
df_phys_cluster_5_vis <- data.frame(
  x = pos_vis[, 1],
  y = pos_vis[, 2],
  cluster_vis = factor(cluster_label_vis, levels = c("5", "Other"))
)
p5 <- ggplot(df_phys_cluster_5_vis, aes(x = x, y = y, color = cluster_vis)) +
  theme_test() +
  labs(title = "Visium: Cluster 5 in Physical Space", color = "Cluster") +
  geom_point(size = 1.0) +
  scale_color_manual(values = cluster.cols_vis) +
  coord_fixed() +
  theme(plot.title = element_text(face = "bold"),,
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5))

# Compute Wilcoxon p-values (two-sided for volcano plot)
pv_vis <- sapply(colnames(mat_vis), function(gene) {
  x1 <- mat_vis[clusterofinterest_vis, gene]
  x2 <- mat_vis[othercells_vis, gene]
  wilcox.test(x1, x2, alternative = "two.sided")$p.value
})
# Avoid p-values of zeros
pv_vis[pv_vis == 0] <- 1e-300

# Compute log2 fold-change
logfc_vis <- sapply(colnames(mat_vis), function(gene) {
  log2((mean(mat_vis[clusterofinterest_vis, gene]) + 1e-6) / (mean(mat_vis[othercells_vis, gene]) + 1e-6))
})

# Subset and visualize the top ten gene markers for cluster 5
de_vis <- data.frame(gene = colnames(mat_vis), pval = pv_vis, neglog10p = -log10(pv_vis), log2fc = logfc_vis)
top_genes_vis <- de_vis[order(de_vis$pval), ][1:10, ]
df <- data.frame(gene = top_genes_vis$gene, logfc = top_genes_vis$log2fc)
p8 <- ggplot(df, aes(x = reorder(gene, logfc), y = logfc, fill = logfc)) +
  geom_bar(stat = "identity") +
  coord_flip() +
  scale_fill_gradient(high = "#00FF99", low = "#99FFD6") +
  theme_test() +
  theme(legend.position = "none") +
  labs(
    title = "Visium: Top Gene Markers for Cluster 5",
    x = "Gene",
    y = expression("log"[2]*"(FC)")
  ) +
  theme(plot.title = element_text(face = "bold"))

# Normalize Xenium data
totgexp_xen <- rowSums(gexp_xen)
mat_xen <- log10(gexp_xen/totgexp_xen * 1e6 + 1)

# PCA on Xenium data
pcs_xen <- prcomp(mat_xen, center=TRUE, scale=FALSE)
plot(pcs_xen$sdev[1:50]) # Scree plot: Will perform tSNE on top 10 PCs as it reaches the elbow of the graph

# Determining the optimal k value for K-means clustering of Xenium data
totw_xen <- sapply(2:25, function(k) {kmeans(pcs_xen$x[,1:10], centers = k, nstart = 10, iter.max = 500, algorithm = "Lloyd")$tot.withinss})
df_totw_xen <- data.frame(k = 2:25, tot.withinss = totw_xen)
ggplot(df_totw_xen, aes(x = k, y = tot.withinss)) + geom_point() + geom_line() + theme_test() # Scree plot: Optimal k = 9 found for K-means clustering

# K-means clustering of Xenium data
clusters_xen <- as.factor(kmeans(pcs_xen$x[,1:10], centers = 9)$cluster)

# Visualize all clustered cell types for Xenium data
df_km_xen <- data.frame(pos_xen, clusters_xen)
p3 <- ggplot(df_km_xen, aes(x = x, y = y, col=clusters_xen)) + 
  theme_test() +
  labs(title = "Xenium: K-Means Clustering", color = "Cluster") +
  geom_point(size = 0.1, alpha = 0.5) +
  scale_color_manual(values = c(
    "1" = "#FF0000", "2" = "#FF9900", "3" = "#CCFF00",
    "4" = "#00FF00", "5" = "#00FF99", "6" = "#0099FF",
    "7" = "#0000FF", "8" = "#9933FF", "9" = "#FF33AA"
  )) + 
  coord_fixed() +
  theme(plot.title = element_text(face = "bold"),
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5))

# Define labels for cluster 1 versus other clusters
cluster_label_xen <- ifelse(clusters_xen == 1, "1", "Other")
# Define colors for cluster 1 versus other clusters
cluster.cols_xen <- c("Other" = "lightgrey", "1" = "#FF0000")
# Define cluster of interest
clusterofinterest_xen <- clusters_xen == "1"
othercells_xen <- clusters_xen != "1"

# Visualize cluster 1 in physical space
df_phys_cluster_1_xen <- data.frame(
  x = pos_xen[, 1],
  y = pos_xen[, 2],
  cluster_xen = factor(cluster_label_xen, levels = c("1", "Other"))
)
p6 <- ggplot(df_phys_cluster_1_xen, aes(x = x, y = y, color = cluster_xen)) +
  theme_test() +
  labs(title = "Xenium: Cluster 1 in Physical Space", color = "Cluster") +
  geom_point(size = 0.1, alpha = 0.5) +
  scale_color_manual(values = cluster.cols_xen) +
  coord_fixed() +
  theme(plot.title = element_text(face = "bold"),
        legend.position = c(1.05, 0.5),
        legend.justification = c("left","center"),
        legend.box.just = "left",
        plot.margin = margin(5, 35, 5, 5))

# Compute Wilcoxon p-values (two-sided for volcano plot)
pv_xen <- sapply(colnames(mat_xen), function(gene) {
  x1 <- mat_xen[clusterofinterest_xen, gene]
  x2 <- mat_xen[othercells_xen, gene]
  wilcox.test(x1, x2, alternative = "two.sided")$p.value

# Avoid p-values of zeros
pv_xen[pv_xen == 0] <- 1e-300

# Compute log2 fold-change
logfc_xen <- sapply(colnames(mat_xen), function(gene) {
  log2((mean(mat_xen[clusterofinterest_xen, gene]) + 1e-6) / (mean(mat_xen[othercells_xen, gene]) + 1e-6))

# Subset and visualize the top ten gene markers for cluster 1

p9 <- ggplot(df, aes(x = reorder(gene, logfc), y = logfc, fill = logfc)) +
  geom_bar(stat = "identity") +
  coord_flip() +
  scale_fill_gradient(high = "#FF0000", low = "#FF8080") +
  theme_test() +
  theme(legend.position = "none") +
  labs(
    title = "Xenium: Top Gene Markers for Cluster 1",
    x = "Gene",
    y = expression("log"[2]*"(FC)")
  ) +
  theme(plot.title = element_text(face = "bold"))

# Plot all panels in one plot using patchwork
panel_spacing <- theme(plot.margin = margin(10, 15, 10, 15))
p1_tag <- p1 + labs(tag = "1.") + panel_spacing
```
