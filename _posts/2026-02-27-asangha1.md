###Summary 
Question: What happens if I do or do not normalize and/or transform gene expression data prior to dimensionality reduction?
I performed PCA on the Xenium dataset in 3 ways: using raw counts, library-size normalized counts, and log-normalized counts (log10(x+1)). Each cell is plotted in 2D PCA space and colored by total gene expression counts per cell. 
In the raw data, PCA produces a tight wedge/triangular shape where PC1 is strongly correlated with total counts per cell. Cells with higher total expression are pulled out as outliers along PC1. Without normalization, PCA is capturing library size differences between cells rather than meaningful biological variation.
After library-size normalization, the shape opens up slightly but remains triangular and skewed, suggesting that correcting for library size alone is insufficient. It is heavily right-skewed due to the large dynamic range of gene expression counts.
After log-normalization, the PCA plot transforms into a blob-like shape with visible substructure, and the correlation between PC1 and total counts disappears. This is because log-transformation compresses the dynamic range, making the data more normally distributed and allowing PCA to capture genuine biological differences between cells rather than technical variation.




```r
data <- read.csv("~/Desktop/Xenium-IRI-ShamR_matrix.csv.gz")
#What happens if I do or not normalize and/or transform the gene expression data 
#(e.g. log and/or scale) prior to dimensionality reduction?
library(ggplot2)
library(gganimate)

gexp <- data[, 4:ncol(data)]
total_counts <- rowSums(gexp)

# Normalization
gexpnorm <- gexp / rowSums(gexp) * mean(rowSums(gexp))
gexpnorm_log <- log10(gexpnorm + 1)

# PCA on Original Data
pc1 <- prcomp(gexp, center = TRUE, scale. = FALSE)
df1 <- data.frame(pc1$x[, 1:2], gene = total_counts, order = 1)

# PCA on Normalized Data
pc2 <- prcomp(gexpnorm, center = TRUE, scale. = FALSE)
df2 <- data.frame(pc2$x[, 1:2], gene = total_counts, order = 2)

# PCA on Log-normalized Data
pc3 <- prcomp(gexpnorm_log, center = TRUE, scale. = FALSE)
df3 <- data.frame(pc3$x[, 1:2], gene = total_counts, order = 3)

# Standardize column names before rbind
colnames(df1) <- colnames(df2) <- colnames(df3) <- c('PC_1', 'PC_2', 'gene', 'order')

# Combine
df <- rbind(df1, df2, df3)
df$order <- factor(df$order,
                   levels = 1:3,
                   labels = c("Original", "Normalized", "Log-Normalized"))

# Animated plot
p <- ggplot(df, aes(x = PC_1, y = PC_2, col = gene)) +
  geom_point(alpha = 0.5) +
  scale_color_gradient(low = "darkgreen", high = "red", name = "Total Counts") +
  labs(title = "PCA colored by Total Gene Counts: {closest_state}", x = "PC1", y = "PC2") +
  transition_states(order, transition_length = 2, state_length = 1) +
  view_follow()

animate(p, nframes = 60, fps = 10, width = 700, height = 500, renderer = gifski_renderer())
anim_save("pca_animation.gif", animation = last_animation())




```
